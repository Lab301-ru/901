04 // ТЕХНОЛОГИЧЕСКИЙ СТЕК

На чём мы
строим.

1 разработчик + AI · сроки и цена ниже студии
STACK · 01 / FRONTEND
Frontend
Next.js (React) + TypeScript — быстрые, SEO-оптимизированные сайты. Vite — для внутренних инструментов. Tailwind CSS + shadcn/ui.
STACK · 02 / BACKEND
Backend и данные
Node.js + TypeScript, PostgreSQL + Prisma. Auth.js — авторизация и роли (RBAC). node-cron + pg-boss — фоновые задачи без просадки скорости.
STACK · 03 / PAY
Платежи и документы
ЮKassa, Тинькофф Эквайринг — приём онлайн-платежей. Автогенерация счетов, договоров и КП в PDF. Статусы заказов и уведомления клиенту.
STACK · 04 / SEARCH
Поиск и каталог
Поиск на PostgreSQL (морфология, опечатки). Импорт каталога от поставщиков (API, XML, Excel). Крупные каталоги — Elasticsearch / Meilisearch.
STACK · 05 / INTEGRATE
Интеграции
REST API — 1С, маркетплейсы, рекламные кабинеты. n8n — автоматизация внутренних процессов. Telegram Bot API — уведомления о заказах.
STACK · 06 / AI
ИИ-инструменты
Чат-ассистенты на RAG, обученные на базе знаний компании. Claude API / Groq — без персональных данных. YandexGPT / GigaChat — сценарии с данными клиента.
STACK · 07 / HOSTING
Хостинг и надёжность
Timeweb Cloud — российские дата-центры, не блокируется РКН. Docker — воспроизводимое окружение. GitHub Actions (CI/CD). Cloudflare (DNS/CDN), Sentry (мониторинг), бэкапы с проверкой восстановления.
STACK · 08 / QA
Тестирование и качество
Vitest — юнит и интеграционные тесты. Playwright — e2e-тесты. Прицельно тестируем платёжные вебхуки, документы и импорт данных.
COMPLIANCE · 152-ФЗ
Соответствие 152-ФЗ — по умолчанию
Персональные данные клиентов хранятся на серверах в России (Timeweb Cloud), без исключений. Для ИИ-сценариев с данными клиентов — только российские модели (YandexGPT / GigaChat), не зарубежные. Это стандартный подход, а не дополнительная опция.
