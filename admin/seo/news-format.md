## Как переносить в админку

| Часть брифа | Куда в админке |
|---|---|
| A | Поля редактора: Заголовок, Адрес, Описание, Теги, Дата, Текст |
| B | SEO → вкладка **◎ Основное** |
| C | SEO → вкладка **◫ Open Graph** |
| D | SEO → вкладка **⌘ Микроразметка** (тип + поля) |
| E | SEO → вкладка **▣ Изображения** (alt у обложки) |

Всё, что не заполнено, наследуется из **⚙ SEO сайта** — пустое поле
не ломает страницу, а подставляет значение по умолчанию. Twitter Card
отдельно заполнять не нужно: если поля пустые, он берёт значения из
Open Graph.

## Что панель делает сама

Эти поля заполнять не нужно — генератор проставляет их при сборке:
`canonical`, `robots`, `sitemap` (приоритет и частота), `hreflang`,
`article:published_time` / `modified_time`, JSON-LD `BreadcrumbList` и
`Organization`, `publisher` с логотипом, `og:url`, `og:site_name`,
`og:locale`, AI-директивы и `robots.txt`.

## Справочно: структура данных

Новость хранится в `news/data/<slug>.json`. SEO лежит в ключе `seo` —
любое поле можно опустить, тогда работает наследование от `seo/site.json`:

```json
{
  "slug": "primer-novosti",
  "title": "Заголовок новости",
  "description": "Короткое описание для списка и соцсетей",
  "cover": "images/news/oblozhka.webp",
  "date": "2026-08-02",
  "updated": "2026-08-02",
  "author": "LAB301",
  "tags": ["тег один", "тег два"],
  "bodyHtml": "<h2>…</h2><p>…</p>",
  "seo": {
    "seoTitle": "Короткий заголовок для выдачи",
    "metaDescription": "Описание 150–160 знаков",
    "focusKeyword": "главный ключ",
    "additionalKeywords": ["синоним", "длинный хвост"],
    "ogTitle": "Цепляющий заголовок для Telegram",
    "ogDescription": "Описание до 110 знаков",
    "schemaType": "FAQPage",
    "schemaData": {
      "questions": [
        { "q": "Вопрос как его ищут?", "a": "Самодостаточный ответ." }
      ]
    },
    "images": [
      { "url": "images/news/oblozhka.webp", "alt": "Описание картинки" }
    ]
  }
}
```

Полный список полей — `emptyPageSeo()` в `admin/seo/domain.js`.
Доступные типы микроразметки: Article, BlogPosting, NewsArticle, FAQPage,
HowTo, Product, Service, Organization, LocalBusiness, Person, Review,
Recipe, VideoObject, SoftwareApplication, WebSite, WebPage.
