Вход

Для записи новостей нужен персональный токен GitHub (fine-grained), ограниченный только этим репозиторием с правом Contents: Read and write. Токен хранится только в этом браузере и никуда не отправляется, кроме api.github.com.

Как создать токен (1 минута)
  1. GitHub → Settings → Developer settings → Fine-grained tokens → Generate new token.
  2. Repository access → Only select repositories → Lab301-ru/lab301.ru.
  3. Permissions → Repository permissions → Contents → Read and write.
  4. Сгенерируйте, скопируйте и вставьте сюда. Поставьте срок жизни; при утере — отзовите токен.
